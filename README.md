# 📈 Exploring Stock Market Trends with Plotly

Interactive financial data visualization dashboard built with Python and Plotly to analyze historical daily stock performance across 10 major fast-food and restaurant industry giants. Includes dynamic metric switching, custom time-range filters, and live GitHub Pages hosting.

## 🔗 Live Interactive Dashboard
👉 **(https://annumasif.github.io/Stock-Market-Trends-Plotly/)**

## 🚀 Features
* **Metric Selector**: Toggle dynamically between `Open`, `High`, `Low`, `Close`, and `Adjusted Close` prices.
* **Time-Range Filters**: Quick-select buttons for `1m`, `6m`, `1y`, `3y`, and an interactive date range slider.
* **Multi-Company Analysis**: Compare stock performance trends across tickers like MCD, SBUX, DPZ, and more.

## 🛠️ Tech Stack
* **Language**: Python 3.x
* **Libraries**: `pandas`, `plotly`
* **Hosting**: GitHub Pages
